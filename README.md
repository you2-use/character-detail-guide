# 캐릭터 상세 가이드

캐릭터 카드 정보를 AI로 정리하거나 직접 작성해 텍스트·HTML 상세 가이드로 저장하고, Marinara Engine의 캐릭터 목록에서 바로 열어 볼 수 있는 확장입니다.

- 확장 버전: **v2.1.0**
- 제작 환경: **Marinara Engine v2.5.0**
- 설치 방법: GitHub 확장 관리자 또는 ZIP 직접 설치

[ZIP 다운로드](https://github.com/you2-use/character-detail-guide/releases/latest/download/marinara-character-detail-guide.personal-extension.zip) · [릴리스 안내](https://github.com/you2-use/character-detail-guide/releases/tag/v2.1.0)

## 주요 기능

- 캐릭터별 상세 가이드를 텍스트 또는 HTML로 작성·저장합니다.
- Marinara에 연결한 AI로 초안을 만들고, 내용을 확인한 뒤 적용할 수 있습니다.
- HTML 초안은 라이트·다크 테마를 선택할 수 있습니다.
- 캐릭터 목록의 프로필 사진을 눌러 저장된 가이드를 읽습니다.
- **모아보기 / 백업**에서 전체 가이드를 관리하고 JSON 파일로 백업·복원합니다.

상세 가이드는 Marinara의 기본 Summary와 별도로 저장되며, 채팅 프롬프트에 추가되지 않습니다.

## 설치 전 준비

이미 외부 확장을 사용하고 있다면 설치 단계로 넘어가세요.

1. Marinara 설치 폴더의 `.env`에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정하고 Marinara를 재시작합니다. 다른 사람이 운영하는 서버라면 운영자에게 요청하세요.
2. **설정 → 고급 → 위험 구역**에서 **타사 확장 가져오기 허용**을 켭니다.
3. **설정 → 애드온 → 외부 확장** 메뉴가 나타나는지 확인합니다.

영어 화면에서는 Settings → Advanced → Danger Zone → Allow third-party extension imports, Settings → Addons → External Extensions입니다. 언어 팩에 따라 일부 메뉴가 영어로 표시될 수 있습니다.

## 설치 방법 1: GitHub 확장 관리자

GitHub 확장 관리자가 설치되어 있고 켜져 있어야 합니다.

1. GitHub 확장 관리자에서 **확장 추가**를 누릅니다.
2. 저장소 주소에 아래 주소를 붙여 넣고 **패키지 찾기**를 누릅니다.

   ```text
   https://github.com/you2-use/character-detail-guide
   ```

3. **manifest.json**을 선택하고 **내용 확인**을 누릅니다.
4. 확장 이름이 **캐릭터 상세 가이드**, 버전이 **v2.1.0**인지 확인하고 **설치**를 누릅니다.
5. **검토 후 켜기**를 열어 코드와 **전체 페이지 접근** 권한을 확인한 뒤 실행을 승인합니다.

공개 저장소이므로 설치하는 사람은 GitHub 로그인이나 토큰이 필요하지 않습니다. 관리자에서는 저장소의 **manifest.json**을 선택하세요.

## 설치 방법 2: ZIP 직접 설치

1. [ZIP 다운로드](https://github.com/you2-use/character-detail-guide/releases/latest/download/marinara-character-detail-guide.personal-extension.zip)를 눌러 파일을 받습니다. **ZIP을 미리 풀 필요는 없습니다.**
2. Marinara에서 **설정 → 애드온 → 외부 확장 → 확장 파일 가져오기**를 엽니다. 영어 화면에서는 **Import Extension File**입니다.
3. 다운로드한 `marinara-character-detail-guide.personal-extension.zip`을 선택합니다.
4. 확장 이름과 버전을 확인하고 가져오기를 완료합니다.
5. **검토 및 실행 / Review and run**에서 코드와 전체 페이지 접근 권한을 검토한 뒤 실행을 승인합니다.

GitHub 확장 관리자가 기본 가져오기 버튼을 숨긴 경우에는 관리자의 **확장 추가 → 파일에서**로 ZIP을 선택하세요.

## 사용 방법

### 상세 가이드 작성하기

1. 캐릭터 편집창을 열고 **카드 → Summary** 영역의 **상세 가이드**를 누릅니다.
2. 연필 모양 편집 버튼에서 **텍스트** 또는 **HTML** 형식을 선택합니다.
3. 내용을 입력하고 **저장**을 누릅니다. **편집 취소**는 저장하지 않은 변경을 버리고 마지막 저장본으로 돌아갑니다.

AI를 사용하려면 편집 화면에서 **AI 작성**을 펼치고 AI 연결·출력 형식을 선택합니다. HTML은 라이트·다크 테마를 선택하고, 필요한 경우 요청 사항과 **카드에 내장된 활성 로어북도 포함**을 설정한 뒤 **AI 상세 가이드 작성**을 누르세요.

완성된 초안을 확인하고 **이 초안 적용**을 누르면 현재 가이드를 초안으로 바꾸고 **즉시 저장**합니다. AI는 저장된 카드 원문을 참고하므로 카드 편집 내용을 먼저 저장하세요. 별도 언어 요청이 없으면 한국어로 작성하도록 지시하며, 결과에 잘못된 내용이 없는지 직접 확인해야 합니다.

### 캐릭터 목록에서 읽기

캐릭터 목록에서 **왼쪽 프로필 사진**을 누르면 저장된 가이드가 읽기 전용으로 열립니다. 폴더 안과 밖의 캐릭터 모두 지원합니다.

뷰어 오른쪽 위에는 **모아보기 아이콘 → 닫기 버튼** 순서로 버튼이 있습니다. 모아보기 아이콘을 누르면 전체 가이드 관리 창으로 이동합니다. 읽기 전용 뷰어에는 편집·AI 작성·저장 기능이 없습니다.

### 모아보기와 백업

편집창이나 읽기 전용 뷰어의 책 모양 **모아보기 / 백업** 아이콘을 누릅니다.

- **내려받기**: 저장된 가이드를 JSON 파일로 백업합니다.
- **불러오기**: 이 확장에서 만든 JSON 백업을 복원합니다. 확인 후 **같은 캐릭터 ID의 기존 가이드를 덮어씁니다.** 백업에 없는 가이드는 유지합니다.
- 가이드가 저장된 캐릭터를 먼저 표시하며, 현재 목록에서 사라진 캐릭터의 저장된 가이드도 확인할 수 있습니다.

저장하지 않은 편집이 있으면 다른 캐릭터 선택·모아보기 이동·백업 작업 전에 **저장**하거나 **편집 취소**해야 합니다. 가이드는 캐릭터 ID로 구분하므로, 카드를 삭제 후 다시 가져와 ID가 바뀌면 기존 가이드가 자동 연결되지 않습니다. 모아보기에서 기존 내용을 확인해 직접 옮겨 주세요.

## 지원 형식과 제한

- 가이드 하나당 최대 **60,000자**를 저장할 수 있습니다. 전체 확장 저장 공간은 UTF-8 기준 약 **950,000바이트** 이내로 제한합니다.
- 백업 불러오기는 이 확장의 JSON 형식만 지원하며 파일 크기는 **2,000,000바이트 이하**여야 합니다.
- AI 참고 자료는 카드 원문과 선택한 내장 활성 로어북입니다. 별도로 연결한 외부 로어북이나 채팅 기록은 포함하지 않습니다. 참고 자료를 JSON으로 변환한 길이가 100,000자를 넘으면 작성을 중단합니다.
- HTML은 `<style>`, 클래스·ID, 인라인 CSS, Flex/Grid, 표, 접기 영역, 반응형 스타일, HTTPS 이미지·배경 이미지를 지원합니다.
- HTML의 JavaScript, 실행 이벤트 속성, iframe/object/embed, form, 외부 스타일시트·웹폰트 등은 차단합니다. 모든 웹페이지를 그대로 표시하는 용도로는 사용할 수 없습니다.
- 같은 폴더에 이름과 프로필 사진이 모두 같은 카드가 여러 장 있으면 목록에서 구별하지 못할 수 있습니다. 이때는 캐릭터 편집창에서 가이드를 확인하세요.
- Marinara 화면 구조에 의존하므로 엔진 업데이트에 따라 호환성 수정이 필요할 수 있습니다.

## 권한과 데이터 처리

이 확장은 캐릭터 목록과 편집창에 버튼을 추가하고 현재 Marinara 서버의 내부 API를 사용하기 위해 **전체 페이지 접근(`full_page_access`)** 권한을 요청합니다. 이 권한은 Marinara 페이지·브라우저 저장소·현재 세션과 네트워크 API에 접근할 수 있으므로 승인 전에 코드를 확인하세요.

가이드와 환경설정은 Marinara의 확장 전용 저장소에 보관합니다. 캐릭터 카드·채팅·프리셋을 수정하지 않으며, 상세 가이드를 채팅 프롬프트에 삽입하지 않습니다.

**AI 작성**을 누르면 카드의 참고 정보, 입력한 요청 사항, 선택한 내장 활성 로어북을 Marinara 서버를 통해 **선택한 AI 연결의 제공자**에게 보냅니다. 해당 연결의 요금과 데이터 처리 정책이 적용됩니다. 일반 열람·편집에는 AI 요청을 보내지 않지만, HTML에 HTTPS 이미지가 있으면 표시할 때 해당 이미지 서버에 요청합니다.

## 업데이트

1. **모아보기 / 백업 → 내려받기**로 가이드를 먼저 백업합니다.
2. GitHub 확장 관리자로 설치했다면 **업데이트 확인 → 업데이트 설치**로 갱신합니다. ZIP으로 설치했다면 새 ZIP을 같은 가져오기 화면에서 불러와 **기존 캐릭터 상세 가이드 확장**의 업데이트를 선택합니다.
3. 업데이트는 꺼진 상태로 저장됩니다. **Review and run** 등 검토 화면에서 변경된 코드·권한을 확인하고 다시 실행을 승인합니다. **Save Disabled Update**는 비활성 상태로 업데이트를 저장하는 버튼입니다.

**업데이트 전에 기존 확장을 삭제하지 마세요.** 확장을 삭제하면 확장 전용 저장소도 삭제됩니다. 같은 확장을 업데이트하면 기존 저장 키·환경설정·JSON 백업 형식을 유지합니다. ZIP으로 설치한 확장을 GitHub에서 업데이트하려면 관리자에서 저장소를 연결하세요.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 외부 확장 메뉴가 없거나 가져오기가 잠겨 있어요. | `.env`의 `ENABLE_EXTERNAL_EXTENSIONS=true`와 위험 구역의 타사 확장 허용 설정을 확인하세요. |
| 상세 가이드 버튼이나 뷰어가 나타나지 않아요. | 확장의 코드·권한을 승인하고 켰는지 확인하세요. 캐릭터 편집창의 Summary 영역을 열거나 페이지를 새로고침하세요. |
| AI 작성에 실패해요. | AI 작성 영역 아래의 **AI 출력 실패** 원인을 확인하세요. 연결·모델·인증 정보·사용량 한도를 점검하고, 참고 자료가 크면 내장 로어북 포함을 해제하세요. 3분 동안 응답이 없으면 자동 중단됩니다. |
| 편집한 내용이 저장되지 않아요. | 일반 편집은 **저장**을 눌러야 합니다. AI의 **이 초안 적용**은 즉시 저장합니다. 저장 실패 메시지가 있으면 원문을 따로 보관하고 원인을 확인하세요. |
| 다른 창에서 변경되었다는 안내가 나와요. | 현재 편집 내용을 따로 복사한 뒤 **편집 취소**로 최신 저장본을 불러오세요. |
| 저장 공간이 부족해요. | JSON으로 백업한 뒤 오래된 가이드 내용을 줄여 저장하세요. 저장 실패 시 기존 저장본은 유지됩니다. |
| 목록에서 캐릭터를 구별할 수 없다고 나와요. | 같은 폴더의 이름·사진이 같은 카드를 확인하고, 캐릭터 편집창에서 해당 가이드를 여세요. |
| 업데이트 후 화면 상태가 남아 있어요. | 업데이트된 코드의 실행을 승인한 뒤 페이지를 새로고침하세요. |

## 업데이트 내역

### v2.1.0

- 폴더 안 캐릭터 표시 순서와 저장된 ID 순서가 달라 다른 캐릭터의 상세 가이드가 열리던 오류 수정
- 캐릭터 목록에서 여는 읽기 전용 뷰어의 닫기 버튼 왼쪽에 모아보기 아이콘 추가
